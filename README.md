# Contacta Floor Monitor - Real-Time Contact Center Monitoring System

## 🎯 Sistema de Monitoreo en Tiempo Real para Contact Center

Plataforma profesional de monitoreo de piso con visualización SVG interactiva, actualización en tiempo real y arquitectura escalable.

## ✨ Características

- **Mapa SVG Interactivo** con zoom, pan y selección de puestos
- **Actualización en Tiempo Real** vía Socket.IO (cambios automáticos cada 3s)
- **Dashboard Profesional** con métricas y estadísticas en vivo
- **40 Puestos de Trabajo** con datos simulados realistas
- **5 Estados Diferentes** (Online, Ocupado, Pausa, Offline, Error)
- **Tooltips Dinámicos** con información detallada
- **Sidebar Inteligente** con detalles del puesto seleccionado
- **Arquitectura Modular** preparada para integraciones futuras
